# Stage 04 — Prototype Data Content

## 1. Summary

The sample rows are now a usable prototype data baseline. The 14 Luban tables contain 34
attributes, 19 formulas, 13 skills with level milestones, the mastery ladder, 12 gear rows,
4 statuses, 4 backgrounds, 31 ranked fighters, four AI profiles, a 12×12 arena, a 32-seat
tournament, reward offers, and 292 bilingual localization entries. Data validation now checks
fighter loadout completeness and equipment/weapon compatibility, gear slot typing, and skill
milestone requirements in addition to the earlier schema rules. Generated readers/metadata and
both generated table trees match this content.

## 5. Not tested, and risks

- **NOT RUN:** Full suite (Unity PlayMode, WebGL build and Playwright). The Fast suite was the
  requested gate for the data-only stage; Full needs a separate Editor-closed build/browser run.
- Running `validate-data.ps1` without `-DataDir` failed because its default points to source
  `data/`, while the validator intentionally consumes generated `.bytes`. The correct explicit
  generated-table invocation passed; the script default was not changed in this stage.
- Content is structurally valid, not gameplay-balanced. Stage 07/08 simulation and Stage 14
  balance work must assess combat outcomes and tune the authored numbers.
- `stat_formula` terms use attribute enum values; the semantic rule catches formula terms for
  which no attribute row exists, while the loader tests also verify the authored attribute set.
